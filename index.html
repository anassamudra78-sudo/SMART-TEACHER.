Belum punya Tautan / Script?

  1. Buat file Google Sheets baru di Google Drive Anda.
  2. Buka menu atas: Ekstensi > Apps Script.
  3. Hapus kode bawaan, lalu salin (copy) kode di bawah ini dan paste ke sana.
  4. Klik Terapkan (Deploy) > Kelola penerapan > Aplikasi web (Akses: Siapa saja).
  5. Salin tautan berakhiran /exec, lalu tempel ke kotak di atas!
